# Source Provenance

## KO/Vela implementation

The PHP, JavaScript, CSS, administration interface, responsive logic, Shadow DOM bridge, tests, documentation, and English accessibility-statement template distributed in this repository were independently written for KO/Vela.

No source file, compiled asset, stylesheet, image, logo, statement template, or administration-interface component from the AccessiYES WordPress plugin is bundled in this plugin.

## Compatibility boundary

This plugin interoperates with the separately hosted AccessiYES CDN widget selected by a site administrator. Compatibility was checked against publicly available AccessiYES documentation, generator output, and distributed runtime behavior. Property names such as `iconId`, `primaryColor`, `modules`, and `_cyA11yConfig` are referenced only because they are the data contract expected by that third-party service.

The site-specific CDN URL is not present in this repository. It is supplied by the administrator and stored in that site's WordPress database.
